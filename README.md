# عصائر طازجة (Fresh Juices)

تطبيق لصفحة هبوط لمحل عصائر طبيعية وطازجة، يحتوي على واجهة جذابة لعرض المنتجات، قسم للطلب السريع، وتفاصيل التواصل. مصمم ليكون متوافقاً مع جميع الأجهزة (الهواتف الذكية، الأجهزة اللوحية، وأجهزة سطح المكتب).

## الميزات
- واجهة ترحيبية (Hero Section) جذابة.
- عرض قائمة العصائر مع الأسعار بتصميم متجاوب.
- بطاقات تفاعلية لكل منتج.
- قسم للتواصل والمعلومات.
- دعم لغة عربية متكامل.

## التقنيات المستخدمة
- Flutter

## تعليمات التشغيل
لتشغيل التطبيق، تأكد من تثبيت Flutter، ثم نفذ الأمر التالي في مجلد المشروع:
```bash
flutter run
```
